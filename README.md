# 🏨 LUXORA – Luxury Hotel Booking Website

A modern and responsive hotel booking website built using **HTML5 and CSS3**. LUXORA showcases luxury hotel rooms, accommodation categories, premium facilities, customer reviews, room prices, and a booking interface.

## 🌐 Live Demo

**Visit Website:** https://bhanumadhavm-design.github.io/luxora/

## 📌 About the Project

LUXORA is a luxury hotel website designed to provide visitors with an elegant and user-friendly experience.

The website features a premium navy blue and gold color combination, beautiful hotel room images, modern typography, and responsive layouts.

It allows visitors to explore different room categories, discover hotel facilities, read customer reviews, and view the booking form.

## ✨ Features

- **Home Section:** Attractive hero section with luxury hotel imagery.
- **Booking Search:** Check-in, check-out, and guest selection interface.
- **About Section:** Introduction to the hotel and its services.
- **Room Categories:** Standard Room, Deluxe Room, and Luxury Suite.
- **Room Pricing:** Displays sample room prices per night.
- **Hotel Facilities:** Swimming pool, restaurant, spa, fitness center, Wi-Fi, and parking.
- **Customer Reviews:** Displays guest testimonials and ratings.
- **Booking Form:** Collects guest details and booking preferences.
- **Navigation Bar:** Easy navigation between website sections.
- **Responsive Design:** Supports desktop, tablet, and mobile devices.
- **Modern UI:** Elegant colors, hover effects, and attractive layouts.

## 🚀 How to Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/bhanumadhavm-design/luxora.git
```

**2. Navigate to the project folder**

```bash
cd luxora
```

**3. Open the project**

Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.
